# 更换主题、箱体和画页

设置里的图片替换无需改代码。`window.flipBank` 是后续开发接口；修改时应等待当前一轮停止。

## 画页

支持 8–24 张正方形 PNG、JPG 或 WebP。完整图片会保留比例并分成上下半页；更改数量时，程序重建叶片、铰点圈、侧盘和导轨，而不是只更换图片索引。

```js
await window.flipBank.setTheme({
  id: 'my-story',
  name: '我的翻页故事',
  pages: Array.from({ length: 16 }, (_, i) => ({
    image: `./assets/story-${String(i + 1).padStart(2, '0')}.png`,
    label: `第 ${i + 1} 页`,
  })),
});
```

资源放在 `public/assets/` 并重新构建。设置上传的图片只保留在当前浏览器会话，不上传、不持久保存。

行情主题结构见 `src/story.js`：`artwork` 和 `atlas: {columns:4,rows:2}` 指向表情图；每页包含 `value`、`expression`、`candles`（OHLC 数组）、`domain`（共同纵轴）、`price`、`date`、`pair`、`interval`。当前默认主题为120根闭环模拟行情；每页显示31根、推进5根，与相邻页共享26根，包括最后一页回到第一页。每根开盘精确等于上一根收盘，所有页使用同一纵轴。盈亏由固定入场价与剧情放大比例计算，正负最多连续2页。`createMarketTimeline(seed)` 可生成另一套可复现的排列；画页生成见 `src/textures.js`。

可选字段 `stopWeights` 为与 `pages` 等长的非负数字数组，至少一个数大于0；不提供时每页等概率。默认24页仍为12张盈利、12张亏损，但盈利页权重1、亏损页权重2，总权重36，因此最终停在盈利页的概率1/3、亏损页2/3。只改变目标页抽签，不改变行情顺序、画页、快翻或停页轨迹；用户上传的主题仍然每页等概率。

## 箱体

```js
window.flipBank.setShell('cream'); // 默认：奶油色圆角外壳
window.flipBank.setShell('wood');
window.flipBank.setShell('mint');
window.flipBank.registerShell('blue-shell', (machine) => {
  // customMaterial 为项目内创建的 Three.js 材质。
  machine.buildCabinet({ material: customMaterial, rounded: true });
});
window.flipBank.setShell('blue-shell');
```

工厂接受 `FlipMachine` 实例。可以更改外部轮廓、材质和细节，但须保留经检查的内腔、轴、前窗、投币槽和币道包络。当前三种外观使用同一币道和碰撞区，因此切换时硬币仍在仓里。更改内构时应同时更新 collider specs 和物理世界；当前接口不能让任意新形状自动获得正确碰撞。

默认奶油箱体采用14mm外轮廓圆角、8mm壁厚；前窗、投币槽和侧轴孔都是真实开孔。粉色窗沿和旋钮、侧面斜纹与星芒图案呼应网页背景。圆角只修改币仓与叶片扫掠范围以外的外部轮廓。

## 机构

尺寸与轨迹集中在 `src/mechanism.js`，单位为米。默认 24 片双面薄页，宽 144 mm、半页长 72 mm、厚 0.18 mm，铰点圈半径 24 mm。`dimensionsFor(count)` 给出 8–24 页各自尺寸，并由 `npm run check` 覆盖。

- 物理叶片 j 正面为 `page[j]` 上半，背面为 `page[j+1]` 下半。停位时上一叶背面与当前叶正面拼成完整画页。
- `leafPose` 给出连续铰链/凸轮约束。模型带侧盘、销、从动轮、导轨和预载弹簧；前窗保持开放，翻动时页尖可以伸出。
- 默认最高 10 页/秒，每轮至少转动 8 秒。通过补足完整圈数延长过程，24 页下转动约 8.06–12.38 秒，另有约 0.46 秒推币和感应延迟。起止速度和加速度归零，同页目标仍实际转动。`planRotation` 的 `minimumDuration` 可调整这段时长；手动拨页不受它影响。
- 手动一页约 1.2 秒；慢翻将机械与硬币时间同时缩为 0.3 倍速度。
- 硬币直径 24 mm、厚 2 mm；槽宽 3.8 mm、高 32 mm。Rapier 固定步长 1/120 秒，启用 CCD，最大 32 枚。

```js
const snapshot = window.flipBank.getSnapshot();
// state, page（从0开始）, count, phase, shell, theme, coins, opened
window.flipBank.insertCoin();
```

修改数量已支持 8–24；32 页需要另一套更大的内腔，不能直接扩展数组。页片不是自由落体纸张模拟，也没有对实体加工公差或纸张柔性进行制造级验证。

## 展示层

`src/official-style.css` 覆盖现有界面的主题风格，`ToyPresentation` 提供背景行情与角色反应。更换主题时同步隐藏久留美特有的背景与反应；箱体、页片和币仓逻辑独立。数值和日文标题的字体随成品提供，不访问外部字体服务。

最终停页盈利时，`celebrationFor(value)` 按幅度选择掌声、欢呼或双音效，`WinConfetti` 从场景两侧喷纸屑和彩带。音频在首次用户操作后开启；右上角可静音。新一轮、换主题、切换到后台会结束庆祝，亏损没有提示音。

最终停页的显示盈亏达到 −100% 时，清空币仓实体和计数，保留槽前下一枚待投的硬币。快翻途中的数字不会触发平仓。`shouldLiquidate` 与显示数字采用同样的取整规则。

触屏与触控笔的硬币命中范围至少为直径56 CSS像素；只有当前视角能看见硬币时才扩大。拖动保持初始接触点偏移，未推过槽口则留在托台上。

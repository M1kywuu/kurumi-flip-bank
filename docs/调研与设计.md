# 调研、改版与对抗性审查

2026-10-03。保留现有网页和机械结构，先看原视频、作者说明、漫画官方资料与角色/互动官网，再修正体验。没有通过 Sites 发布。

## 原作的核心

[奈櫻Nine的参考视频](https://www.bilibili.com/video/BV1pEa66NEct/)可见木质箱体、中央横轴、上下拼合的久留美与行情画页。快速翻页制造“得意—恐慌”的反差，停止又把某一页变成结果。[作者制作页](https://anenin.weebly.com/2516325622212053005927231.html)说明感应器、马达、翻页动画与调速的组合；视频观众用暂停获得结果，是视频媒介的补偿。按用户选择，网页每次投币预抽目标、实际旋转到该页，没有暂停玩法。

内部制动结构未在原视频充分展示。本网页为另行设计的铰链/凸轮机构，不声称复原原箱内部。

## 角色与作品语气

对照 [KADOKAWA第1卷](https://www.kadokawa.co.jp/product/322104000242/)、[第2卷](https://www.kadokawa.co.jp/product/322109000348/)、[漫画宣传资料](https://group.kadokawa.co.jp/information/promotional_topics/article-3117.html)和[动画官网](https://fxkurumi-info.com/)。新插画采用粉色短发、分束刘海、小白发夹、浅色上衣与细黑领结；去掉旧版本的黑发箍和普通制服感。8 幅表情强化小瞳孔、汗滴、惊恐和哭喊。

台词围绕“赚回来”的执念、得意、否认回调、突然失控。当前中文是本作新写的二创台词，没有复制官网长段文字，也没有把新画当成官方素材。

## 逐项修改

| 旧页面问题 | 当前修改与体验价值 |
|---|---|
| 英文编号、重复操作说明、收藏计数分散注意力 | 首页收拢到箱子、一句反应、盈亏、投币；帮助移到“关于” |
| 通用产品介绍与“好运小冒险”文案 | 用得意、否认、惊慌的短句随盈亏变化 |
| 结果面板像普通科技演示卡片 | 去掉大边框和进度装饰，直接突出跳动的数字 |
| 12 页与 4 表情，角色辨识度不足 | 24 行情画页、8 幅按漫画参考重绘的表情 |
| K线像单独随机画的波形 | 按用户选择改为连续模拟 OHLC、相邻滑动窗口、固定价格刻度与首尾闭环 |
| 翻页慢，盈亏只在停止后出现 | 峰值 10 页/秒；全程插值更新盈亏，停前减速让结果可读 |
| 盈亏反差没有事件感 | 高涨或急跌出现短促漫画字，跌势配轻微镜头震动及可选声音 |
| 开盖只展示结构 | 停下后开盖发现“硬币一枚没少”，让剧情损失与真实存钱形成笑点 |
| 替换内容仍限定12张 | 支持8–24页，并重建真实页片和导轨 |

没有加交易仪表盘、任务列表、成就墙、自动轮播或无关背景场景：它们不能改善投币、行情失控与发现硬币的主体验。

## 行情和数字：本轮更新

用户明确选择连续模拟行情，替换上版固定历史片段。保留原有箱体、24页和角色；将涨跌的编排与图线连接同时修正。

- 一条120根OHLC闭环，每页显示31根并推进5根，相邻共有26根，首尾页也成立。下一根开盘等于上一根收盘；统一纵轴让相同价格保持相同高度。横轴为相对位置，没有真实日历或1D标识。
- 12个正值、12个负值，种子随机打散，闭环中最多连续两页同号；不强制一正一负。多种幅度和8种表情都实际使用。
- 端点由剧情数值决定，5根之间使用有端点约束的随机扰动连接，影线和实体长度有变化。多数涨跌较小，极端结果较少；不能为做反差把每根都画成规则锯齿。
- 虚拟入场155.4；数值为 `round((close / 155.4 - 1) × 100 × 500)`。500是固定的剧情显示放大比例，不代表真实交易杠杆、账户收益或强平机制。首屏和图中标模拟，关于页明确为虚拟剧情。
- 转动保持峰值10页/秒，增加完整圈数延长到8.06–12.38秒；另有推币/感应延迟。抽中的目标不变，起止仍平滑。手动拨页保持约1.2秒。

对抗性审查反对直接洗牌独立历史图片：它会让图线、时间和数字关系断裂；也反对24根周期配31根窗口，因为同屏会出现重复周期。120根周期大于31根窗口，同时5根承接一次方向反转，可兼顾连续性与变化可见性。拒绝每页随机调整显示倍率；固定倍率确保价格和盈亏一致。

上版通过 [Alpha Vantage FX_DAILY](https://www.alphavantage.co/documentation/#fx-daily) 取得的100根USD/JPY日线保留在 `src/fx-history.json`（2026-10-03取得、最后刷新2026-10-02）。当前仅参考其中影线占比来生成不同蜡烛形态；当前价格、画页和盈亏全部为模拟，未将历史日期当作虚构行情的日期。

OHLC语义仍参考 [TradingView字段定义](https://tradingview.github.io/lightweight-charts/docs/api/interfaces/CandlestickData)与[蜡烛系列说明](https://tradingview.github.io/lightweight-charts/docs/series-types)：实体为开/收，影线为高/低。颜色按开收关系决定，红涨绿跌。该设计追求可信的图形结构和玩具体验，不宣称统计复现真实外汇市场。

## 对抗性审查与修正

| 被挑战的判断 | 反例 / 修正 |
|---|---|
| 全卡刚性径向固定即可 | 正面被遮住、无法独立翻落；改为独立铰接、上圈切向收纳、下圈垂挂 |
| 24页只需翻倍数组 | 半径17mm净距不足；改为24mm铰点半径、0.18mm薄页、扩大的侧盘与24个铰点 |
| 更大半径总是更好 | 28mm让页尖侵入币道；24mm兼顾页距与投币包络 |
| 旧前框与横杆可原样保留 | 新页尖/导轨更低；降低前窗下沿、移除干涉横杆，保留凸轮下段支撑 |
| 高速运动可以纯重力解释 | 叶尖峰速约4.16m/s；采用轻薄页、预载弹簧和导轨约束，保持开放前窗 |
| 必须每次至少转整圈 | 24页会拖长等待；先抽目标、整数步停位；本轮按用户反馈补足完整圈数，保持快翻，延长到约8–12秒 |
| 翻页只在最后替换正面贴图 | 侧面会暴露假机构；每片始终使用固定双面纹理，上下相邻叶拼页 |
| 任意箱形都能沿用旧物理 | 改内腔会破坏碰撞；外壳接口保留已验证包络，内构变化另行验证 |
| 平放硬币进入窄道可无限累积 | 数枚后堵塞；竖向滚入宽仓，真实求解器检查32枚后限定容量 |
| 相机旋转等于箱体旋转 | 重力会随镜头变化；只旋转观察镜头，箱子始终直立 |
| 快速数字随机刷新更刺激 | 会与纸页错配并失去走势；数字按连续模拟页插值、角色与停页数据同步 |

技术使用 [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)、[Raycaster](https://threejs.org/docs/pages/Raycaster.html)和CanvasTexture；硬币使用 [Rapier刚体](https://rapier.rs/docs/user_guides/javascript/rigid_bodies/)、[碰撞与感应器](https://rapier.rs/docs/user_guides/javascript/colliders/)、[CCD](https://rapier.rs/docs/user_guides/javascript/rigid_body_ccd/)。构造参考 [Scott Bezek实物split-flap](https://github.com/scottbez1/splitflap)与[Mutoscope专利](https://patents.google.com/patent/US549309A/en)，未复制CAD。声音须用户主动开启，参照 [Web Audio平台限制](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。

结论为当前网页方案可行。数值抽样、刚体测试和实际视角检查支持视觉与运动可信度，不等同实体加工验证。
